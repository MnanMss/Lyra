# 更新下载

安装包、续传残片与解压目录保存在 Electron 用户数据目录的 `updates` 下，按版本隔离，
不再使用共享系统临时目录中的固定路径。新建目录和文件在 Unix 上分别采用 `0700`、`0600`，
过期版本仅在该私有目录内清理。

下载进度只包含已经完成文件写入的字节。暂停先中止网络读取，等待当前写入与文件关闭结束，
再报告保留在 `.part` 中的实际大小；续传的 `Range` 从这个大小开始。

取消控制器在首次发布下载进度前就绪，因此续传刚开始时也可以暂停。取消会在下载结束后删除
残片；网络中断会保留已完成写入的部分。服务器忽略 `Range` 时覆盖重下，完整下载仍须通过
发布校验和后才能用于安装。
