# 会话通知

后台回合的完成和失败提示直接来自 `agent_end` 状态变化，不等待列表刷新。相同结束事件只提示一次，
下次运行可以再次提示；主动取消不提示。打开会话会清除对应提示，较晚到达的列表刷新不会补弹旧结果。

应用内提示与系统通知都按 session ID 定位会话。冷窗口的列表尚未加载时补读目标；补读过程中发生新的
会话选择，旧请求不能再抢走焦点。不存在的会话和读取失败需要明确反馈，不能无声关闭提示。

侧栏折叠时只保留一个静态状态点，优先级为等待处理、执行失败、已完成，颜色沿用会话行的状态色。
当前会话不计入未读提示。任务提示只提供查看和关闭操作，不重复提供新建排查入口。

系统通知仅在窗口未聚焦、最小化或关闭时发送。正常完成发送完成通知；所有 `approval_request` 都发送
待处理通知，其中 `kind: interactive` 或 `subject: ask_user` 表示等待回复，其余表示等待批准。
普通审批只展示标题，不将完整命令和详细参数复制到系统通知。答案仍通过审批接口返回，不注入全局聊天。
